# Finding the story in what was filmed

The outline is a plan; the recordings are what exists. This job reads what the host actually said and decides what the story is.

## Find these, in this order
1. **The question.** The one thing the video answers. State it as a question a viewer would ask. If you cannot, the video has no spine yet: say so in the logline.
2. **Where it is answered.** The sentence where the answer lands. Everything before it is setup; everything after it is aftermath.
3. **The opening.** The strongest first thing a viewer could hear: a result, a failure, a claim they will want to test. Prefer one that can be shown on screen, not only said. Name the sentences.
4. **The setback.** Where something went wrong or turned out harder. Without one, the video is flat; if there is none, say so.
5. **The payoff.** The moment the answer is shown.
6. **Weak or repeated.** Passages that explain what the picture shows, repeat a point already made, or wander. Only list a passage when removing it would make the video better, not merely shorter.
7. **Good moments nobody planned.** A joke, a mistake the host owns, a reaction, an honest opinion, a line said better off the cuff than it could be written. List these as moments to keep. They are what viewers remember.

## Order
Change the order only when a first-time viewer would follow the new order better: a term explained before it is used, the setback before the fix, the payoff not given away early. If the recorded order already works, leave it and list nothing.

## Never
- Never list a sentence the host marked good (locked) as weak.
- Never invent a moment: every id comes from the cut.
- Never decide, only report: the host decides what changes.
