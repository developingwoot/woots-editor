# Starter skills

These are the craft notes Claude reads when it cuts, scripts, designs and publishes your videos. They are written to suit any talking-head channel.

Make them yours: put a file of the same name in `~/.claude/skills/<skill>/` (or the folder named by `WOOTS_SKILLS_DIR`) and the app uses your copy instead of the starter one.
A file only this folder has is used as it is. Your name, channel and voice come from the channel profile (Settings), not from these files.

- `youtube-edit/rough-cut.json`: the numbers for the rough cut (pause length, piece length, zoom, ...). `rough-cut.md`, `cut-rules.md`, `editing-style.md`: the rules Claude follows.
- `youtube-script/`: how an outline is shaped: hooks, structure, teaching points.
- `youtube-graphics/`: the look of graphics and how they are built (HyperFrames).
- `woots-channel/`: your house style and brand (colours, fonts). Fill `brand.md` in.
- `youtube-publish/`: titles, descriptions, chapters.
