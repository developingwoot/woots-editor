# Graphics

Read `style-guide.md` (the look), `motion-style-reference.md` (how things move), `hyperframes.md` (how a graphic is built) and `overlays.md` (transparent overlays over the face).

A graphic exists to teach or to show one thing. If it does neither, leave it out. If a graphic cannot work (it must cover the face), say so and leave it out.
