# Transparent overlays

A graphic that sits over the speaker is rendered with an alpha channel (`--format mov`, ProRes 4444) from a page whose `html`, `body` and stage backgrounds are transparent.
Keep it in the bottom third or a side panel so the face stays visible. Floating labels must not collide with the title.

## Numbers and names
When the host says a price, a count, a size or a name that the picture does not already show, show it: a large number on its own card for a figure that is the point, a small label in a corner
for a name (a game title, a part, a program). Several reference videos did both. Leave out a number that is only part of a sentence.
